# 🐳 Docker Basics

## 🧱 Docker
Docker is a platform to **build, run, and manage applications** in isolated **containers**. It ensures apps run the same on any system.  
**Advantages:** lightweight, portable, consistent environments, easy deployment.

## 🖼️ Docker Image
An **image** is a **read-only blueprint** for creating containers. It includes application code, dependencies, and runtime.  
**Example:** `docker pull nginx`  
**Advantage:** reusable and portable.

## 📦 Docker Container
A **container** is a **running instance of an image**. It is isolated and lightweight.  
**Example:** `docker run -d -p 8080:80 nginx`  
**Advantages:** ephemeral, portable, consistent.

## 🌐 Docker Network
Docker **networks** connect containers to each other or the Internet.  
**Types:** bridge (default), host, none, overlay.  
**Example:** `docker network create my_network`  
**Advantage:** enables secure container communication.

## 💾 Docker Volume
A **volume** is persistent storage for containers. Data survives container removal.  
**Example:** `docker run -v my_volume:/data nginx`  
**Advantage:** data persistence and sharing.

## ⚙️ Docker Compose
**Compose** manages **multi-container apps** with a single YAML file.  
**Example:**
```yaml
version: '3'
services:
  web:
    image: nginx
    ports:
      - "8080:80"
  db:
    image: mysql
    environment:
      MYSQL_ROOT_PASSWORD: password
