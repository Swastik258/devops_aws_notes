# 🐳 Docker — Quick Notes

Docker is a **platform for building, running, and shipping applications in containers**.  
Containers are lightweight, portable environments that package your app and its dependencies.

---

## ⚙️ Basic Concepts

- **Image** → Blueprint of your container (like a snapshot).
- **Container** → Running instance of an image.
- **Dockerfile** → Script that defines how to build an image.
- **Docker Hub** → Public registry to store and share images.
- **Volume** → Used for persisting data.
- **Network** → Connects containers.

---

## 📦 Common Docker Commands

| Command | Description |
|----------|--------------|
| `docker --version` | Check Docker version |
| `docker ps` | List running containers |
| `docker ps -a` | List all containers (including stopped) |
| `docker images` | Show downloaded images |
| `docker pull <image>` | Download an image from Docker Hub |
| `docker run <image>` | Run a container |
| `docker stop <container>` | Stop a running container |
| `docker rm <container>` | Remove a container |
| `docker rmi <image>` | Remove an image |
| `docker exec -it <container> bash` | Open shell inside a container |

## 🧱 Example: Simple Dockerfile

```dockerfile
# Use Node.js base image
FROM node:18-alpine

# Set working directory
WORKDIR /app

# Copy files
COPY package*.json ./
RUN npm install

# Copy source code
COPY . .

# Expose port and run app
EXPOSE 3000
CMD ["npm", "start"]
