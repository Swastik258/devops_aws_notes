# 🧩 What is Git?

**Git** is a version control system that tracks changes in code.  
It helps developers **save versions**, **work together**, and **avoid losing progress**.

---

## ⚙️ Why Git Was Created
Git was created by **Linus Torvalds** in **2005** to manage large projects like the Linux kernel.  
It helps teams manage code efficiently with full history tracking.

---

## 🧠 Common Git Commands

```bash
git init        # Initialize a repository
git add .       # Add files to staging
git commit -m "message"  # Save changes
git log         # Show commit history
git status      # Show current state
