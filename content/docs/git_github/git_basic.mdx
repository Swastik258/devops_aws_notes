# 🧩 Git and GitHub — Complete Beginner Guide

Git and GitHub are essential tools for developers to manage, track, and collaborate on code efficiently.
They help keep a history of changes, work in teams, and share code globally.

---

## 🧠 What is Git?

**Git** is an open-source **version control system** that helps you track changes in your project files.
It allows you to:

- Save versions of your code (commits)
- Revert to old versions
- Work on multiple branches without losing data
- Collaborate with others without conflicts

You use Git **locally on your computer** to manage your code history.

---

## 🌐 What is GitHub?

**GitHub** is a **cloud-based platform** that hosts Git repositories online.
It lets you:

- Store your code safely in the cloud
- Collaborate with teammates
- Contribute to open-source projects
- Track issues and manage pull requests

So in short:
👉 **Git = version control tool (local)**
👉 **GitHub = online hosting for Git repositories**

---

## ⚙️ Step 1: Install Git

To install Git on Ubuntu or any Linux system:

```
sudo apt update
sudo apt install git -y
```

Check version:

```
git --version
```

---

## 🧾 Step 2: Configure Git

Set your Git username and email (these details appear in commits):

```
git config --global user.name "Your Name"
git config --global user.email "youremail@example.com"
```

Check your config:

```
git config --list
```

---

## 📁 Step 3: Create a Local Repository

Create a new project directory:

```
mkdir myproject
cd myproject
```

Initialize Git inside the folder:

```
git init
```

This creates a hidden `.git` folder — your project is now a Git repository.

---

## 📄 Step 4: Add and Commit Files

Create a file (for example, `index.html`) and add content.

Now check the file status:

```
git status
```

Add the file to Git tracking:

```
git add index.html
```

Commit the file (save version):

```
git commit -m "Initial commit"
```

Each commit represents a **snapshot** of your project at a certain time.

---

## ☁️ Step 5: Create a Repository on GitHub

1. Go to [https://github.com](https://github.com)
2. Log in to your account
3. Click **New Repository**
4. Give it a name (e.g., `myproject`) and click **Create Repository**

You’ll get a repository URL like:

```
https://github.com/your-username/myproject.git
```

---

## 🔗 Step 6: Connect Local Git to GitHub

Link your local repository with the remote GitHub repository:

```
git remote add origin https://github.com/your-username/myproject.git
```

Check connection:

```
git remote -v
```

---

## 🚀 Step 7: Push Your Code to GitHub

Now upload (push) your local commits to GitHub:

```
git branch -M main
git push -u origin main
```

After this, your code will be visible on your GitHub repository online.

---

## 🔄 Step 8: Pull Changes from GitHub

If you or your team make updates on GitHub, bring those updates to your local system:

```
git pull origin main
```

---

## 🌿 Step 9: Working with Branches

To create a new branch:

```
git branch feature-login
```

Switch to the branch:

```
git checkout feature-login
```

After making changes, add and commit them:

```
git add .
git commit -m "Added login feature"
```

Push the branch to GitHub:

```
git push origin feature-login
```

You can then create a **Pull Request (PR)** on GitHub to merge your branch with the main code.

---

## 🧹 Step 10: Basic Git Commands Summary

```
git status        # check file status
git add .         # add all files
git commit -m ""  # save changes
git push          # upload to GitHub
git pull          # download latest code
git branch        # list branches
git checkout      # switch branches
```

---

## ✅ In Simple Words

- **Git** keeps track of your project versions locally.
- **GitHub** stores those versions online for collaboration.
- Together, they make it easy to build projects, track changes, and work in teams — safely and efficiently.
