# ☸️ Install Kubernetes Using KIND and Create Cluster

---

## 🧠 What is KIND?

**KIND (Kubernetes IN Docker)** is a lightweight tool to **run Kubernetes clusters locally** using Docker containers.
It’s mainly used for:

- Learning Kubernetes
- Local testing
- CI/CD pipeline validation

It runs your entire cluster (control plane + worker nodes) **inside Docker**, so you don’t need any VMs or cloud setup.

---

## ⚙️ Step 1: Install KIND and kubectl

We’ll install **KIND** and **kubectl** manually using a shell script.

### 🧩 Create the Install Script

```bash
vim install_kind.sh
```

Paste the following script inside:

```bash
#!/bin/bash

# Download KIND binary (for x86_64 systems)
[ $(uname -m) = x86_64 ] && curl -Lo ./kind https://kind.sigs.k8s.io/dl/v0.20.0/kind-linux-amd64

# Make it executable and move to system path
chmod +x ./kind
sudo cp ./kind /usr/

# Install kubectl (v1.30.0)
VERSION="v1.30.0"
URL="https://dl.k8s.io/release/${VERSION}/bin/linux/amd64/kubectl"
INSTALL_DIR="/usr/local/bin"

curl -LO "$URL"
chmod +x kubectl
sudo mv kubectl $INSTALL_DIR/

# Verify installation
kubectl version --client

# Clean up temporary files
rm -f kubectl
rm -rf kind

echo "✅ KIND & kubectl installation complete."
```

---

### 🧩 Run the Script

```bash
chmod 777 install_kind.sh
./install_kind.sh
```

✅ This installs both:

- **KIND** → cluster tool
- **kubectl** → CLI to interact with Kubernetes

You can verify:

```bash
kind version
kubectl version --client
```

## ☸️ Step 2: Create a Kubernetes Cluster Using KIND

We’ll create a **3-node cluster** — 1 control-plane + 2 workers.

---

### 1️⃣ Create a Directory

```bash
mkdir kind-cluster
cd kind-cluster
```

---

### 2️⃣ Create a Configuration File

```bash
vim config.yml
```

Paste the following YAML configuration:

```yaml
kind: Cluster
apiVersion: kind.x-k8s.io/v1alpha4

nodes:
- role: control-plane
  image: kindest/node:v1.31.2
- role: worker
  image: kindest/node:v1.31.2
- role: worker
  image: kindest/node:v1.31.2
  extraPortMappings:
    - containerPort: 80
      hostPort: 80
      protocol: TCP
    - containerPort: 443
      hostPort: 443
      protocol: TCP
```

Save and exit using:

```
ESC :wq ENTER
```

---

### 3️⃣ Create the Cluster

Run the following command:

```bash
kind create cluster --name my-cluster --config config.yml
```

⏳ KIND will now create:

- 1 Control Plane (Master Node)
- 2 Worker Nodes

Each node runs as a **Docker container**.

---

## 🔍 Step 3: Verify Cluster

Check cluster details:

```bash
kubectl cluster-info
```

List all nodes:

```bash
kubectl get nodes
```

Expected output:

```
NAME                      STATUS   ROLES           AGE   VERSION
my-cluster-control-plane   Ready    control-plane   1m    v1.31.2
my-cluster-worker          Ready    <none>          1m    v1.31.2
my-cluster-worker2         Ready    <none>          1m    v1.31.2
```

---

## 🧹 Step 4: Delete the Cluster (if needed)

To delete everything:

```bash
kind delete cluster --name my-cluster
```
